# Approval Governance: AUTO vs HUMAN

- **`AUTO_APPROVAL_HIGH_V2.0`**: Autonomous pipeline for candidates meeting strict mathematical score isolation and zero veto conflicts.
- **`HUMAN_APPROVED_IMPORT_V6`**: Operator-reviewed pipeline utilizing static Markdown review sheets and cryptographically bound JSON manifests (`handoff_hash`, `approval_hash`). Replay and stale evidence protection prevents executing expired or modified files.
